# Banco Python - Versão 2

## Sobre o projeto
Segunda versão do sistema bancário desenvolvido em Python, com melhorias na organização do código e armazenamento persistente dos dados.

## Funcionalidades
- Consulta de saldo
- Depósitos
- Saques
- Extrato bancário
- Validação de valores
- Armazenamento de dados em arquivo JSON
- Recuperação dos dados ao iniciar o programa

## Tecnologias
- Python
- JSON

## Como executar
Execute o arquivo banco.py pelo terminal:

python banco.py
